# Habit Tracker

Habit Tracker makes weekly routines visible with a day-by-day check-in grid and current streak counts.

## Interface

The weekly grid lists habits down the left and seven dates across the page. A weekly summary counts check-ins, and controls move between weeks.

## Features and use

Add a habit from the top field. Toggle a cell to record or undo a check-in for that date. Move between weeks to review earlier dates. Remove a habit after confirming; its check-in history is removed with it.

## Data and limits

Habits and checked dates are saved in localStorage on this device. Streaks count consecutive checked calendar dates ending today. The tracker does not send reminders or sync across browsers.

## Run locally

Use Node.js and npm, then run these commands from the project folder:

```sh
npm install
npm run dev
```

The app is built with React and Vite. Check the source and production build with:

```sh
npm run lint
npm run build
```

## Deployment

The public app is published with GitHub Pages at [https://a2rp.github.io/habit-tracker/](https://a2rp.github.io/habit-tracker/). To build and publish the current version, run:

```sh
npm run deploy
```
